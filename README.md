# My Drone Journey

A small personal website about learning to fly drones, from a roughly £90 budget drone to the DJI Mini 4K, including practical safety lessons and the enjoyment of getting outdoors to take aerial photographs.

## Live website

https://jazblue.github.io/my-drone-journey/

## Related websites

- Main drone website: https://jayskentdrones.pro/
- Drone photo gallery: https://jazblue.github.io/drone-gallery/

## Publishing

This is a static HTML site hosted with GitHub Pages from the `main` branch and repository root.

## Note

The content is a personal account, not a formal product review or legal guidance. Always check the drone manufacturer's current specifications and the UK rules and restrictions applicable to your flight.
